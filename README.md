一个可直接在浏览器打开和编辑的 19 页通用 HTML 演示模板。

## 使用方式

下载 `index.html` 后，使用最新版 Chrome 或 Edge 打开即可。

模板包含 19 页通用页面，适用于项目汇报、研究答辩、技术评审、方案说明和产品汇报。页面中的文本可以直接编辑，也支持演示、缩放、备注、图片和 HTML 导出等功能。

项目为单文件 HTML，不需要安装依赖或启动后端服务。
